# DOM-001 execution plan

- Status: Active
- Story: [DOM-001](../../backlog/epics/01-domain-capture.md)
- Started: 2026-07-21
- Owning area: `packages/domain`

## Initial state

- Epic 00 provides typed package boundaries, executable tests, architecture
  enforcement, CI, and dependency security.
- `@replay/domain` exports no concepts yet and has no runtime dependency.
- Product vocabulary names UTC instants and half-open ranges but their exact
  public representation and equality semantics need to be specified.

## Plan

- [ ] Refine the story with explicit domain terminology and observable
      acceptance examples before implementation.
- [ ] Define UTC instant construction, serialization, ordering, and equality.
- [ ] Define non-empty half-open time ranges and their boundary operations.
- [ ] Define identifier types whose values are supplied by application ports.
- [ ] Cover invalid input, equality, midnight, and DST presentation boundaries.
- [ ] Export only stable domain concepts through `@replay/domain`.
- [ ] Run focused domain checks, architecture validation, full checks, build,
      and security audit.

## Architectural frame

- Owning layer: pure domain.
- Ports/adapters: ID creation will be supplied through an application port in a
  later story; the domain only validates supplied identifiers.
- Invariants: timestamps represent UTC instants; ranges are half-open and
  non-empty; invalid values never construct; equality is deterministic.
- Forbidden dependencies: clock, UUID generation, timezone database, OS,
  filesystem, SQLite, Tauri, React, network, and AI.
