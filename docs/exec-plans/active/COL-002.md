# COL-002 execution plan

- Status: Active
- Story: [COL-002](../../backlog/epics/03-collection.md)
- Started: 2026-07-22
- Owning area: application collector port and `packages/collector`

## Plan

- [ ] Define an application-owned Git-context source and explicit health states.
- [ ] Resolve repository identity, worktree root, branch or detached HEAD, and
      current commit through bounded Git commands.
- [ ] Normalize remote-derived repository identity and strip embedded
      credentials before it crosses the port.
- [ ] Avoid file contents, diffs, status output, commit messages, and other
      prohibited metadata.
- [ ] Degrade safely for non-Git directories, linked worktrees, submodules,
      deleted folders, missing Git, malformed output, and command timeouts.
- [ ] Add deterministic fixture tests and a local Git integration boundary test.
- [ ] Run focused and repository-wide harness checks.

## Architectural frame

- Owning layers: application port and collector adapter.
- Inward-facing port: Git-context observation source.
- External adapter: bounded Git process execution in `packages/collector`.
- Invariants: captured context contains only repository identity, worktree root,
  branch or detached state, and commit; credentials and repository contents
  never cross the port.
