# DOM-002 execution plan

- Status: Active
- Story: [DOM-002](../../backlog/epics/01-domain-capture.md)
- Started: 2026-07-21
- Owning area: `packages/domain`

## Initial state

- DOM-001 provides immutable UTC instants and typed identifiers for event
  identity and occurrence times.
- The architecture contract defines an observed-event envelope and requires
  append-only, versioned evidence.
- Event payload terminology, privacy classes, and unsupported-version behavior
  still require an executable domain contract.

## Plan

- [ ] Define the event envelope and stable source/privacy terminology.
- [ ] Model the initial payload kinds without prohibited content.
- [ ] Validate event and payload versions as positive integers.
- [ ] Preserve unknown kinds or unsupported versions as opaque evidence.
- [ ] Freeze events and payloads so accepted facts cannot be mutated.
- [ ] Add construction, privacy, compatibility, and immutability tests.
- [ ] Run focused domain checks, architecture validation, full checks, build,
      and security audit.

## Architectural frame

- Owning layer: pure domain.
- Ports/adapters: none; later application use cases supply IDs and observation
  times, while collectors supply observable payload input.
- Invariants: accepted events are immutable; occurrence and observation times
  stay distinct; payloads are discriminated and versioned; unknown evidence is
  retained without reinterpretation.
- Forbidden content: source code, diffs, window titles, clipboard, keystrokes,
  screenshots, browser URLs, prompts, secrets, and environment variables.
