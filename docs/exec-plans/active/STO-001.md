# STO-001 execution plan

- Status: Active
- Story: [STO-001](../../backlog/epics/02-storage.md)
- Started: 2026-07-21
- Owning area: `packages/storage`

## Plan

- [ ] Select the smallest maintained SQLite library compatible with Tauri.
- [ ] Define configurable database-location and connection boundaries.
- [ ] Implement ordered, idempotent, transactional migrations.
- [ ] Configure WAL mode and foreign keys explicitly.
- [ ] Preserve the previous usable schema when migration fails.
- [ ] Add integration tests against temporary real SQLite databases.
- [ ] Run focused and repository-wide harness checks.

## Architectural frame

- Owning layer: storage adapter.
- External adapter: SQLite only; no domain/application rules live here.
- Invariants: migrations are ordered and atomic, paths are configurable in
  tests, and startup failure includes recovery guidance without data loss.
