## Architectural frame

- Owning area: repository tooling only.
- Ports/adapters: none; the checker reads manifests and source imports.
- Invariants: dependencies point inward, adapters do not import one another,
  cross-package imports use public entry points, and desktop may compose all
  packages.
- ADR required: no; this enforces the accepted architecture contract.

## Prohibited changes

- Product behavior, domain types, external I/O, new package relationships, or
  exceptions not already allowed by the boundary matrix.
