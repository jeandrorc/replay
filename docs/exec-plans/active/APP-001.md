# APP-001 execution plan

- Status: Active
- Story: [APP-001](../../backlog/epics/01-domain-capture.md)
- Started: 2026-07-21
- Owning area: `packages/application`

## Plan

- [ ] Define inward-facing clock, identifier, and observed-event repository
      ports at the application boundary.
- [ ] Define validated collector input distinct from accepted domain facts.
- [ ] Implement event recording with application-supplied ID and observed time.
- [ ] Make duplicate observation IDs idempotent.
- [ ] Map repository failures to stable, redacted application errors.
- [ ] Add use-case tests with controllable in-memory port fakes.
- [ ] Run focused and repository-wide harness checks.

## Architectural frame

- Owning layer: application.
- Ports: clock, ID generator, and observed-event repository.
- Adapters: test fakes only; production adapters belong to later stories.
- Invariants: collectors do not create accepted IDs or observation timestamps;
  duplicates do not create a second fact; errors leak no sensitive payload.
